# Cardex 视觉资产

色值以 `cardex-tokens.json` 为准（VI v15）。

## 文件

| 文件 | 用途 |
| --- | --- |
| `cardex-tokens.json` | 颜色、字体、状态签 |
| `logo.svg` / `logo-dark.svg` | 标志，浅底 / 深底 |
| `wordmark-light.svg` / `wordmark-dark.svg` | 字标 |
| `lockup-light.svg` / `lockup-dark.svg` | 标志和字标的组合 |
| `readme-header-light.png` / `readme-header-dark.png` | README 头图 |

## 使用规则

- 不改标志和字标的形状、比例、配色。这些文件是定稿。
- 蓝只做品牌：字标下划线、链接、索引卡上的 2px 首行线。不用蓝色表示状态，也不拿它铺大面积装饰。
- 签色只表状态（排队、进行、测试、复核、待拍板、合并、失败、暂停）。不把签色用在图标底、插图装饰或和状态无关的色块上。
- 浅底品牌蓝 `#2F5BEA`，深底品牌蓝 `#5B8CFF`。正文用墨色 `#16161A` 或纸白 `#F5F4EF`。亮黄和浅青只做图形，不做正文。
