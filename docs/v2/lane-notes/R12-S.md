# R12-S

## 做了什么

`sandbox.Profile` 在调用方目录和 `os.TempDir()` 之外，把 `/tmp` 交给现有 `expandPaths`，因此同时覆盖 `/tmp` 和 `/private/tmp`。不放行整个 `/var`、`/private/var` 或用户家目录。

`WritablePaths` 保留原有路径，只追加当前进程环境里已经点名的目录。变量未设置或为空则不追加，不编造路径，不解析 shim。Claude：`CLAUDE_CONFIG_DIR`、`CLAUDE_CODE_PLUGIN_CACHE_DIR`。Grok：原有 `grokHome()`，外加非空 `GROK_LOG_FILE` 的父目录、非空 `GROK_LOG_DIR`。OpenCode：非空 `OPENCODE_DB` 的父目录。Kimi：`KIMI_CODE_HOME`、`KIMI_CODE_CACHE_DIR`，以及非空 `ConfigHome`。Cursor：`CURSOR_CONFIG_DIR`、`CURSOR_DATA_DIR`。AGY：`homePath(".gemini")`、`cachePath("gemini")`、非空 `GEMINI_CLI_HOME`。

`AGY.Build` 在模型名以 `-low`、`-medium` 或 `-high` 结尾，或名字含 `thinking` 时，不再追加 `--effort high`。两者都没有的模型仍默认 `--effort high`。

目标钉选只在卡的 Channel 与 Model 都为空，并且下面任一成立时，不走 `explicitPin` 早返回，进入现有候选池：卡是 `KindReview` 且钉选 family 等于 `authorFamily`；或钉选模型不满足 `Card.Requires`。仅钉 Model 时，family 与 Requires 按 `matchPinned` 会返回的渠道判定：有健康提供方用第一个健康渠道，都无健康则用第一个提供方。family 先取定位表，定位表没有 family 则取该渠道 family。有合法异族候选就选它；没有则返回现有 `ErrNoCandidate`，不派给作者同族，也不新造错误。与复核族和 Requires 都不冲突的目标钉选仍早返回，优先于 pace。卡级 Channel 或 Model 仍按原钉选走，并优先于目标。对不上的钉选本身不是冲突。都无健康时不进入候选池，`matchPinned` 仍返回现有 `ErrPinnedUnavailable`。`FrozenRoute` 未改。

## 没做什么，以及原因

没有改默认 schedules、ranking 产品行为、结果类别、返工计数或状态流转。没有改 `FrozenRoute`、admission、`internal/model`、`internal/store/migrate.go`、`go.mod`、`internal/loop/ranking.go`。没有取消沙箱，没有放行整个 `/var` 或家目录，没有解析 shim，没有跑真实渠道。`docs/v2/design.md` 与 `v2` 逐字节相同。

## 接口请求

无。最终 diff 不改 `internal/repocheck/`，且 `docs/v2/design.md` 与 `v2` 一致。

## 已知问题

这些目录只在 Cardex 进程环境里已经有对应变量时放行。只写在 shim 里的路径不会放行。卡级 Channel 或 Model 仍优先于目标，并按卡级指定走。
