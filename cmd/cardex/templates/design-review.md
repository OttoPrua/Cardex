## 风险与收益预算（先于对抗展开）

先按本卡真实影响面裁剪审查强度，目标是尽快形成可用交付，而不是最大化 finding 数量：

- 低风险（文档、静态配置、角色→工具映射、disabled/零路由候选数据）：只核对明确验收项、实际消费路径和直接相关测试；不得扩张成全仓 canonical、schema 穷举、mutation 矩阵或新的复审链。P2 仅登记，不派修复卡。
- 中风险（普通实现、非生产内部接口）：聚焦改动 diff、现役调用方和定向测试；只有可复现且影响当前可达路径的 P0/P1 才阻塞。
- 高风险（认证授权、执行真值、递归/批量删除、资金或生产写入、不可逆外部动作）：才执行完整对抗审查，并仍限制在本卡声明的现役路径。
- 同一交付默认只做一次独立复审。不要把措辞、理论防御、未启用功能或范围外历史失败升级为 P0/P1；环境不具备范围外全量门时，如实披露，不得据此制造修复轮。

下方通用检查项只在与上述风险和审核关注点直接相关时执行；低风险卡不要求逐维度穷举。

## 开工自门:镜像现场 vs 指纹文件

本自门只针对已配置并完成同步的镜像工作区。若 {{DIR}} 是本机原始工作区——判据:目录内**既无** `.claudego-fingerprint` **也无** `.claudego-scripts/`——则跳过本节,直接进对抗审查(本机现场即真相,无"镜像过期"可言)。两者只有其一时按下文正常走自门(残缺镜像必须报,不得借豁免放行)。

1. **fingerprint 文件在否**——读取 `{{DIR}}/.claudego-fingerprint`。若文件缺失,立即在文末输出下面 JSON 并停卡(禁止对 {{DIR}} 出任何 verdict、禁止读代码假装通过):
   `{"verdict":"block","p0":["镜像过期:{{DIR}}/.claudego-fingerprint 缺失,同步未落盘 fingerprint.复审拒绝背书"],"p1":[],"p2":[],"summary":"镜像过期,禁止复审"}`
2. **现场 vs 指纹**——优先跑镜像内脚本,第一条能跑通即用:
   - `{{DIR}}/.claudego-scripts/verify-mirror-fingerprint.ps1`（参数 `-Mirror {{DIR}}`）
   - 或 `{{DIR}}/.claudego-scripts/verify-mirror-fingerprint.sh {{DIR}}`
   退出码 `0`:一致,进入对抗审查。非 0:输出 block JSON 停卡,不得以环境缺陷空跳自门。脚本都不可用时,用只读 git 与哈希原语按指纹文件核对现场后再决定 pass/block。
3. **自门通过**再进入下方对抗性审查。自门失败一律不得给出 pass/concerns 结论——只能 block。

对抗性纪律:
1. 先了解项目结构与近期改动(git log / git diff,通读关键文件),列出改动声称达成的目标。
2. **逐项证伪**:对每个声称,构造至少一个能推翻它的具体场景(边界输入/并发时序/崩溃点/契约消费方视角),用源码与测试证据判定攻防结果;"测试全绿"不构成通过理由——检查测试本身是否断言了真正的契约(测试被改弱=P0)。
3. **契约面专项**:改动是否悄改了既有接口/枚举/路径/schema 的语义(对照契约文档与上游消费方,逐字段核);向后兼容声称要用旧形状输入实际验证。
4. **第一性核查**:新增复杂度是否有已证需求支撑(必要性测试);承重假设逐条标证据等级(源码证实/实测/推断/未验证),未验证的承重假设=发现。
5. 维度覆盖:架构一致性、正确性风险、边界条件、并发与状态管理、安全性、可维护性。
6. 这是只读审查:不要修改任何代码文件。
6a. **平台口径**:验收平台以被审卡契约声明为准。cardex 默认 darwin/Linux 与原生 Windows x64 CI 覆盖范围为验收平台。Windows x64 已有原生 CI；ARM64 产物尚未实机验收。Windows 不支持 hosted PTY Goal 和要求严格退出证明的自动跨执行器回退。不得把未运行的 Windows 运行时当作已验收，也不得以未在 Windows 实跑单独判 p0/p1 或 block——卡契约未含的平台观察至多记 p2。
6b. **安全面措辞**:涉负例构造/攻击枚举的审查项,一律以"确认这些情形返回 deny/被拒绝"的防御性回归口径书写,禁用攻击教程式语气。
7. 输出结构化审核报告:问题按 P0(必须修)/P1(应该修)/P2(建议)分级,每条注明文件位置、**证伪场景**与理由,并给出修复思路;通过项也要写"试图击破的角度+为何未破"。

最后,把结论汇总为一个 ```json 代码块(供机器解析,务必是合法 JSON):
{"verdict":"pass|concerns|block","p0":["..."],"p1":["..."],"p2":["..."],"summary":"一句话结论"}
